How the review and repeat cycle works

Decisions here are saved on this browser only. Export them, then run npm run stencils:review -- path-to-reviews.json to persist them in the repository. Mark rework with specific notes; edit the individual composition, run npm run stencils and reopen this sheet. Approval expires when a drawing, its source variants, its three closest matches, or any of those matches changes. Review each flagged pair side by side and explain why it is distinct, or mark it for rework. A change to either drawing invalidates the pair decision. npm run stencils:check -- --approved --complete blocks release until every drawing is approved, every flagged pair is resolved, and every source entry is mapped.

SVGs and editable Excalidraw libraries share the same authored geometry. Excalidraw's own renderer can produce slightly different rough strokes. Originals are preserved as references; aliases are not additional drawings. Coverage counts source entries, not distinct service concepts.
